# Lennart Reichow · Portfolio

Static portfolio website, hosted with GitHub Pages: https://lennartreic.github.io/Portfolio/

- `index.html`, `work/`, `research/`: the pages (generated)
- `assets/`: stylesheet, script, images, videos, CV
- `_build/content.py`: all texts and image references. Edit here.
- `_build/build.py`: regenerates the HTML pages (`python3 _build/build.py`)

Large videos are not stored in this repository. They are embedded from YouTube.
